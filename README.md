## Overview

An AI-powered market research assistant built on a **RAG (Retrieval-Augmented Generation)** architecture. Users input an industry keyword and receive a structured, Wikipedia-grounded industry report generated by GPT.

## How It Works (RAG Pipeline)

1. **Step 1 — Intelligent Classification**: LLM rewrites and validates the user's keyword into a formal economic industry term, rejecting abstract or invalid inputs
2. **Step 2 — Retrieval**: LangChain `WikipediaRetriever` fetches top-5 relevant documents (2,000 chars each) as grounding context
3. **Step 3 — Generation**: GPT synthesizes retrieved context into a structured 480-word industry report with fixed sections (Overview / Key Insights / Summary)

## Key Features

- RAG pipeline: Wikipedia-grounded generation prevents hallucination
- LLM semantic validation before retrieval (filters invalid inputs)
- Structured report with enforced word limit (480 words)
- Secure API key input — user-provided at runtime, never stored in code
- Session state management across multi-step workflow

## Security Note

The OpenAI API key is entered by the user at runtime via a password-masked sidebar input. No credentials are hardcoded or stored in this repository.

## How to Run

1. Clone the repo and install dependencies:
```bash
pip install - requirements.txt
```
2. Run the app:
```bash
streamlit run streamlit_assignment.py
```
3. Enter your OpenAI API key in the sidebar and start researching

## ⚠️ Model Compatibility Note

This app was built using `gpt-5.2` via the OpenAI API. As OpenAI regularly updates 
available models, if you encounter model errors, replace `gpt-5.2` in the selectbox 
with a currently available model such as `gpt-5.5` or `gpt-5.2-chat-latest`.

Check the latest available models at: https://platform.openai.com/docs/models
